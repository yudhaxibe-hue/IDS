Academic Project Specification & Methodology

Explainable Adaptive AI-Based Intrusion Detection System

Academic Master of Engineering (M.E.) Demonstration Prototype

Three Core Architectural Contributions:
  1. Machine Learning Detection: Bidirectional network flow feature extraction evaluated with Random Forest / Extra Trees models.
  2. Explainable AI (XAI): Local SHAP feature attribution with plain-language, deterministic translation for security analysts.
  3. Concept Drift Adaptation: Statistical drift surveillance with candidate model evaluation sandboxing (no unverified self-training).
Privacy & Trust Architecture:
  • 100% Local Inference — zero paid third-party cloud APIs.
  • Strict Loopback Binding (`127.0.0.1`) with per-session token protection.
  • No raw packet payloads are stored, exported, or transmitted.
  • Observable local machine traffic only — no unverified network-wide claims.
